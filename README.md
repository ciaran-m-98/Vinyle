# Vinyle

A small Next.js starter for a daily music puzzle. Puzzle content is fictional
sample data, and the record illustration is an original CSS placeholder.

## Getting started

```bash
npm install
npm run dev
```

The app includes the daily puzzle at `/`, a list of sample puzzles at `/archive`,
and archived puzzle pages at `/archive/[date]`. Update
`src/features/puzzle/data.ts` to replace the placeholder content. Guess
submission and the help button are visual placeholders only.

Useful checks:

```bash
npm run lint
npm run build
```
